## 버그 수정

### BUG#1 — Ops Bot 왼쪽/가운데 패널 미동작

**근본 원인**: `max_tokens: 2000` 제한으로 Claude 응답이 잘려서 `process-cards` 블록이 누락됨.  
추가 원인: 시스템 프롬프트가 process-cards를 응답 **마지막**에 출력하도록 지시하고 있었음.

**파일**: `backend/src/api/routes/ops.ts`, `frontend/src/pages/OpsCenter.tsx`

**수정**:
```typescript
// ops.ts — max_tokens 증가
max_tokens: 4096  // 2000 → 4096

// OpsCenter.tsx — process-cards를 응답 첫 번째로 출력하도록 시스템 프롬프트 재구성
응답 형식 (이 순서를 반드시 지키세요):
1. 먼저 process-cards 블록을 출력하세요 (필수, 생략 금지)
2. 그 다음 n8n 워크플로우 JSON
3. 마지막으로 구현 단계별 한국어 가이드
```

**결과**: 왼쪽 프로세스 카드 패널 + 가운데 n8n JSON 패널 정상 작동.
