## [#2] Ops Bot 연속 자동화 무한 로딩 버그 수정

### 문제
첫 번째 자동화 완료 후 두 번째 자동화 요청 시 무한 로딩. 원인: 대화 히스토리에 `process-cards` 블록과 n8n JSON이 통째로 포함돼 다음 Claude API 호출이 컨텍스트 초과 또는 스트림 오류 발생.

### 해결

**OpsCenter.tsx**
1. `stripCodeBlocks()` — 컴포넌트 외부 순수 함수로 정의. assistant 메시지에서 `` ```process-cards `` 및 `` ```json `` 블록을 `[이전 자동화 결과 생략]`으로 치환.
2. `AbortController` (`abortRef`) — 새 요청 시 이전 SSE 스트림을 즉시 abort.
3. 히스토리 슬라이싱 — 최근 10개 메시지만 API 전송.

```typescript
// 컴포넌트 외부 (재렌더링에 영향 없음)
function stripCodeBlocks(content: string): string {
  return content.replace(/```(process-cards|json)[\s\S]*?```/g, '[이전 자동화 결과 생략]').trim()
}
```

## [#3] Ops Bot 패널 UX 개선

### 좌측 패널 — 플로우차트 카드

- 각 카드: `STEP N` 배지 (top-left) + 제목 + 담당 역할 + 필드/단계/주의사항 카운트 배지
- 카드 간 연결: 세로 선 + SVG 삼각형 화살표 (다운 방향)

```tsx
<div className="flex flex-col items-center my-1">
  <div className="w-px h-3 bg-[#27272a]" />
  <svg width="10" height="6" viewBox="0 0 10 6">
    <path d="M5 6L0 0h10L5 6z" fill="#3f3f46" />
  </svg>
</div>
```

### 중앙 패널 — 상세 필드 + 클릭 가이드

- `CopyFieldBtn` 컴포넌트: 복사 버튼 내장, 1.5초 후 자동 리셋
- 각 필드: 어두운 카드 + 필드명 + 복사 버튼 상단 행, sky-300 monospace 값, info 아이콘 + 주석
- "복사해서 바로 사용" 배지 표시
- 단계별 클릭 경로 가이드 ("단계별 클릭 경로" 배지 추가)

### 시스템 프롬프트 강화

- `fields` 섹션: "실제 복사 가능한 설정값" 명시
- `guide` 섹션: "실제 클릭 경로" 포함 지시 (예: `설정 > Credentials > + Add Credential > HTTP Header Auth`)

**도구 배지 그리드 (`OnboardingPage.tsx`)**
- 표시 순서: nvm → Node.js → Python → pyenv → Homebrew(Mac) → Git → Claude Code → VS Code → WSL2(Win)

  - Linux: nvm → Node (nvm) → pyenv → Python → Git → Claude Code
