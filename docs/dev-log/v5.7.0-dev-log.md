### 2. 사이드바 메뉴 순서 재구조화 + 이름 변경 (AppLayout.tsx)

#### 문제
기존 구조에서 `agents` DB에서 불러온 봇 아이콘(research/content 등)이
로고 바로 아래 위치해 대시보드·미션보드보다 먼저 렌더됨.

또한 메뉴 이름이 서비스 정체성과 맞지 않음:
- 'Growth Studio' → 서비스에서는 'Growth Bot'
- 'Ops Center' → 서비스에서는 'Ops Bot'

#### 변경 내용

**NAV_ITEMS를 3개 그룹으로 분리:**
```
TOP_NAV_ITEMS: 대시보드, Mission Board
BOT_NAV_ITEMS: Growth Bot, Studio Bot, Ops Bot
UTIL_NAV_ITEMS: CDP 뷰, 승인 인박스, 비용 추적, 설정
```

**사이드바 렌더 순서 (변경 후):**
```
로고 (O)
───────────
대시보드
Mission Board
───────────
봇 패널 토글 (5-dot)
[DB 봇 아이콘 — research/content 등 동적]
───────────
Growth Bot
Studio Bot
Ops Bot
───────────
CDP 뷰 · 승인 · 비용 · 설정
[flex-1 공백]
봇 추가 (+)
```

### 3. Ops Bot — process-cards 파싱 fallback 추가 (OpsCenter.tsx)

#### 문제
SSE 스트리밍에서 `done` 이벤트에 조건 `&& parsed.text`가 있어,
done 이벤트가 `text` 없이 발행되면 delta로 누적한 `fullText`의 `process-cards` JSON이 파싱되지 않음.
→ 왼쪽 카드 패널 빈 상태 유지

#### 변경 내용
1. `done` 이벤트 조건 완화: `eventName === 'done' && parsed.text` → `eventName === 'done'`
   - `parsed.text`가 있으면 `fullText` 업데이트, 없으면 기존 누적 `fullText` 사용
2. `cardsSet` 플래그 추가: done 이벤트에서 카드 파싱 성공 시 `true`
3. while 루프 종료 후 fallback: `!cardsSet && fullText` 조건으로 재파싱
   - done 이벤트 누락이나 text 미포함 경우에도 카드 생성 보장
