## 1. 고객 원클릭 세팅 전략 — 방향 C (하이브리드)

### 배경
책의 핵심 차별화 요소: "터미널 한 줄로 모든 게 세팅된다"

문제: OOMNI 고객 중 GitHub 자체가 진입 장벽인 분들 존재 (50대 퇴직자, 비개발자)

### 채택 방향: C — 하이브리드

```
일반 OOMNI 사용자 (비개발자)
  └── 앱 내 자동 세팅 (온보딩 1회 클릭으로 6봇 + 미션 자동 구성)

책 독자 / 파워유저 / 개발자
  └── GitHub 퀵스타트 스크립트
       └── github.com/yongal74/oomni-quickstart
            └── curl 한 줄 → 설치 → OOMNI 유료 플랜으로 전환
```

### 앱 내 세팅 강화 방향 (v5.8.0~)
- 온보딩 Step 3에서 "OOMNI 팀 자동 구성" 옵션을 **기본 선택 상태**로
- API 키 입력 후 바로 "시작하기" 가능 (중간 단계 최소화)
- 온보딩 완료 즉시 튜토리얼 오버레이 (첫 봇 실행까지 가이드)

### GitHub 퀵스타트 전략 (책 연동)
- 책 안에 QR코드 + URL 삽입
- `setup.sh` 실행 시: 의존성 자동 설치 → OOMNI 다운로드 → 실행
- 책 독자가 OOMNI 유료 고객으로 전환되는 퍼널

## 3. 상용화 기능 — v6.0+ 적용

### 결제 / 라이선스
- **결제 시스템**: Stripe (해외 포함) 또는 KG이니시스 (국내)
- **플랜 구성 (안)**:

| 플랜 | 가격 | 내용 |
|---|---|---|
| Free | 0원 | 1미션, 2봇, 월 100 AI 호출 |
| Pro | 월 29,000원 | 무제한 미션, 6봇, n8n 연동 |
| Team | 월 99,000원 | Pro × 5인, 공유 미션, 관리자 |

- **라이선스 키**: 구매 시 키 발급 → 앱 첫 실행 시 인증
- **책 독자 전용 코드**: 책 구매자에게 3개월 Pro 무료 쿠폰

### 계정 / 동기화
- 이메일 계정 가입 (Supabase Auth 또는 Clerk)
- 미션·봇 설정 클라우드 동기화
- 멀티 디바이스 지원

### 자동 업데이트
- `electron-updater` 적용
- GitHub Releases 기반 자동 업데이트
- 업데이트 시 릴리즈 노트 인앱 표시

### 운영 인프라
- **오류 추적**: Sentry (Electron + React)
- **사용 분석**: PostHog (어떤 봇이 얼마나 쓰이는지)
- **인앱 고객 지원**: Crisp 또는 Intercom 위젯

## 4. 보안 강화 — v5.8.0 즉시 적용

### 발견된 취약점

#### 🔴 HIGH — Claude API 키 평문 저장 의심
- **위치**: `settingsApi.setApiKey()` → SQLite DB
- **위험**: 로컬 DB 파일 탈취 시 API 키 노출
- **수정**: `electron.safeStorage.encryptString()` 로 암호화 후 저장

#### 🔴 HIGH — 내부 API 인증 키 하드코딩
- **위치**: `OpsCenter.tsx:415` — `internalKey = 'dev-key'`
- **위험**: 누구나 `localhost:3001` 에 `dev-key`로 API 호출 가능
- **수정**: 앱 시작 시 랜덤 UUID 생성 → IPC로 frontend에 전달 → 매 요청마다 검증

#### 🟡 MEDIUM — Backend 포트 외부 노출 가능성
- **위치**: backend `localhost:3001` 바인딩 설정
- **위험**: `0.0.0.0` 바인딩 시 같은 네트워크에서 접근 가능
- **수정**: `127.0.0.1` 명시적 바인딩 강제

#### 🟡 MEDIUM — Electron contextIsolation / nodeIntegration
- **위험**: `nodeIntegration: true` 이면 XSS → OS 명령어 실행 가능
- **수정**: `contextIsolation: true`, `nodeIntegration: false` 확인 및 강제

#### 🟡 MEDIUM — CORS 설정 미검증
- **위험**: backend가 모든 origin 허용 시 CSRF 공격 가능
- **수정**: `cors({ origin: 'http://localhost:5174' })` 명시적 화이트리스트

## 5. 책 ↔ OOMNI 연결 생태계 전략

```
책 출판 (국문 1판)
    │
    ├── QR코드 → GitHub 퀵스타트
    │       └── 설치 → OOMNI 무료 체험 → Pro 전환
    │
    ├── 책 내 쿠폰 코드 → 3개월 Pro 무료
    │
    └── "OOMNI로 직접 해보세요" → 앱 내 튜토리얼 연동
            └── 책 챕터와 앱 기능 1:1 매핑 가이드
```

### 프롬프트 템플릿 20개 (책 → 앱 연동)
- 책에 수록된 20개 템플릿을 OOMNI 앱 내 "프롬프트 라이브러리"로 제공
- 책 독자는 앱에서 바로 불러다 쓸 수 있음
- 향후 사용자 커스텀 템플릿 저장 기능으로 확장
