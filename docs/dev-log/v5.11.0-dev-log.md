# OOMNI v5.11.0 개발 세션 로그

## 개요

Studio Bot에 Open Design 에디터 통합. 기존 Studio Bot의 4번째 모드로 추가하여 사이드바 변경 없이 UI/그래픽/빌드/Open Design을 한 곳에서 제공.

---

## Open Design 통합 (nexu-io/open-design)

### 아키텍처 결정

- **후보**: nexu-io/open-design (완전 로컬), Penpot (Docker 자체 호스팅), Plasmic (클라우드 SaaS)
- **선택**: nexu-io/open-design — 로컬 퍼스트, API 키 불필요, npx로 바로 실행, OOMNI와 동일한 Electron 아키텍처
- **통합 방식**: npm 데몬(포트 7456)을 OOMNI 백엔드에서 child_process로 스폰 → Studio Bot 내부 iframe으로 임베드

### Open Design 특징
- 71개 디자인 시스템 내장 (Material, Tailwind UI, Shadcn 등)
- AI(Claude Code 연동)로 랜딩페이지·앱 UI·컴포넌트를 자연어로 생성
- 완전 로컬 실행 (인터넷 없이도 동작)

### 충돌 여부
- 기존 Studio Bot = AI 채팅 기반 디자인/코드 생성
- Open Design = 로컬 비주얼 에디터 (AI 어시스트)
- **완전히 다른 역할** → 동일 페이지 내 탭으로 공존, 충돌 없음

## 변경 내용

### backend/src/api/routes/setup.ts

**pnpm 감지 추가:**
- `checkVersion('pnpm')` 호출
- `pnpm_all: 'npm install -g pnpm'` 설치 명령어 추가

**Open Design 데몬 관리 엔드포인트:**

```typescript
const OPEN_DESIGN_PORT = 7456
let openDesignProc: ChildProcess | null = null

// isPortOpen(): net.Socket으로 포트 7456 리스닝 여부 체크
// GET  /api/setup/open-design/status  → { running, port, url, pid }
// POST /api/setup/open-design/start   → spawn('npx', ['open-design-ade', '--port', '7456'])
// POST /api/setup/open-design/stop    → proc.kill('SIGTERM')
```

핵심 로직:
- `BROWSER=none` 환경변수 → 브라우저 자동 열기 방지
- 최대 15초 폴링 (1초 간격) → 서버 기동 확인
- `stdio: 'ignore'` → 자식 프로세스 출력 억제
- Windows: `npx.cmd`, 기타: `npx`

### frontend/src/pages/StudioBotPage.tsx

**새 타입/상수:**
```typescript
type StudioMode = 'ui-proto' | 'graphic' | 'build' | 'open-design'
const OPEN_DESIGN_PORT = 7456
```

**MODES 배열에 추가:**
```typescript
{ key: 'open-design', label: 'Open Design', icon: PenTool, role: 'design' }
```

**상태 관리:**
```typescript
type OdStatus = 'idle' | 'checking' | 'starting' | 'running' | 'error'
const [odStatus, setOdStatus] = useState<OdStatus>('idle')
const [odError, setOdError] = useState('')
```

**3개 함수:**
- `checkOdStatus()` — GET /api/setup/open-design/status 폴링
- `startOd()` — POST /api/setup/open-design/start
- `stopOd()` — POST /api/setup/open-design/stop

**useEffect**: mode === 'open-design' 전환 시 자동 상태 확인

**헤더 UI**: 실행 중 배지(포트 번호 포함) + 시작/중지 버튼 + 새로고침

**콘텐츠 패널**:
- `odStatus === 'running'`: `<iframe src="http://localhost:7456" />` (full-screen)
- `odStatus !== 'running'`: 시작 버튼 + 사전 요구사항 안내 + 에러 표시

**좌측 패널**: open-design 모드 시 카테고리 대신 에디터 정보 + 새 창 열기

**플로팅 채팅**: `mode !== 'open-design'` 조건으로 자동 숨김

### frontend/src/pages/OnboardingPage.tsx

- `ToolStatus`에 `pnpm: string | null` 추가
- pnpm 배지 표시 (nvm → Node → Python → pyenv → pnpm → Homebrew → Git → Claude Code → VS Code → WSL2)
- 미설치 시 `npm install -g pnpm` 명령어 + "Open Design 에디터용" 레이블
