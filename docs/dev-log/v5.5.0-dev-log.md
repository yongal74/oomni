## Stage 5 — Content Bot: 문체/톤 + 글자 수 조절

### 기존
- 채널별 스타일 free-text 입력 필드

### 변경 내용

**문체/톤 5개 버튼 선택** (`TONE_OPTIONS`)
| 키 | 레이블 | 설명 |
|---|---|---|
| casual | 캐주얼 | 친근하고 일상적인 표현 |
| formal | 격식체 | 전문적이고 공식적인 문체 |
| authority | 권위형 | 전문가적 통찰과 확신 |
| empathy | 공감형 | 독자의 감정에 공명하는 문체 |
| humor | 유머 | 가볍고 재치있는 톤 |

**글자 수 슬라이더 + ±100 조절 버튼**
- `<input type="range">` + 최소/최대 레이블 표시
- ± 버튼으로 100자 단위 조절
- 최솟값 50, 최댓값 채널별 maxChars
- 프롬프트에 선택된 톤과 글자 수 자동 포함
