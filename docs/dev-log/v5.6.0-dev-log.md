## Stage 1 — OpsCenter: 완전 재설계

### 배경
v5.5.0까지의 OpsCenter는 좌측 패널에 도메인별 예시가 정적으로 나열되어 있고, 패널 역할 분리가 불명확했다. 사용자는 평소에는 Left 패널이 비어 있다가 AI가 자동화 설계를 완료하면 결과가 카드 형태로 채워지는 동적 구조를 요구했다.

### 레이아웃 구조

| 영역 | 역할 |
|---|---|
| **Top Bar** | 6개 도메인 드롭다운 버튼 + 4개 빠른 실행 프롬프트 → 클릭 시 Right 채팅 입력창에 텍스트 주입 |
| **Left Panel** | 기본 비어 있음. AI가 process-cards 생성 완료 후 자동화 프로세스 카드 목록 표시 |
| **Center Panel** | Left에서 카드 선택 시 → 실행순서 체크리스트 + FIELD/설정값 테이블 + 주의사항 + 가이드 표시 |
| **Right Panel** | AI 채팅 (SSE 스트리밍). 입력 + 대화 히스토리 |

### Top Bar 상세

**도메인 드롭다운 (6개)**
- 재무·회계, 인사·HR, 영업·CRM, 마케팅·콘텐츠, 운영·SCM, IT·보안

**각 도메인당 5~8개 빠른 프롬프트 아이템** — 클릭하면 `injectPrompt(text)` 호출:
1. 드롭다운 닫기
2. 입력창에 텍스트 세팅
3. `inputRef.current?.focus()` 포커스

**상단 빠른 실행 버튼 4개**
- 전체 프로세스 분석 · 자동화 추천 · 비용 절감 포인트 · 리스크 체크

### process-cards 시스템

```typescript
interface AiProcessCard {
  id: string
  title: string
  role: string
  steps: string[]
  fields: Array<{ name: string; value: string }>
  warnings: string[]
  guide: string
}
```

**동작 흐름:**
1. 사용자 입력 → Right 패널 AI가 SSE 스트리밍으로 응답
2. 스트리밍 완료 후 `parseAiProcessCards(fullText)` 호출
3. ` ```process-cards [...] ``` ` 블록 파싱 → `setProcessCards(cards)`
4. Left 패널에 카드 목록 자동 렌더링

**시스템 프롬프트 업데이트:**
AI에게 응답 마지막에 `process-cards` JSON 블록을 반드시 포함하도록 지시. 각 카드는 `id`, `title`, `role`, `steps`, `fields`, `warnings`, `guide` 필드를 포함.

### Center Panel 상세

선택된 카드 기준으로 4개 섹션 표시:
1. **실행 순서** — 체크박스 토글 가능 (완료 시 strike-through)
2. **FIELD / 설정값** — `fields` 배열을 2컬럼 테이블로 렌더
3. **주의사항** — `warnings` 배열을 경고 배지로 렌더
4. **가이드** — `guide` 텍스트

## Stage 2 — Studio Bot: 플로팅 채팅 + 폰트 크기 + 배경색

### 배경
v5.5.0에서 채팅창을 하단 고정 패널로 변경했으나, 사용자는 콘텐츠 위에 플로팅(부유)하는 형태를 원했다. 또한 "화면 키우기"로 구현된 설정을 폰트 전체 크기 조절로 교체하고, 배경색 선택 기능을 추가 요청.

### 변경 내용

**플로팅 채팅창**
```
기존: shrink-0 하단 고정 패널 (결과↑, 채팅↓ flex-col)
변경: absolute bottom-6 left-1/2 -translate-x-1/2 z-20
      backdrop-blur-sm, rounded-2xl, shadow-2xl
```
- 결과 영역: `flex-1 relative overflow-hidden` → `absolute inset-0 overflow-y-auto`
- 채팅창: 위 결과 위에 부유, 접힘(`w-[600px] h-[180px]`) / 펼침(`w-[660px] h-[340px]`)
- `max-w-[calc(100%-32px)]` 로 모바일/소형 창에서도 잘림 방지

**폰트 크기 조절 (S/M/L/XL)**
```typescript
const [fontSize, setFontSize] = useState(13)
// S=11 / M=13 / L=15 / XL=17
```
- Left 패널 설정 영역에 4개 버튼 배치
- 결과 영역 `absolute inset-0` div에 `style={{ fontSize: `${fontSize}px` }}` 적용
- 화면/창 크기 zoom과 무관한 텍스트 크기 조절

**배경색 5가지**
```
Dark    | #0d0d0f   (기본값, 빈 문자열)
Navy    | #0a0e1a
Slate   | #0f172a
Carbon  | #111318
Forest  | #0a1a0f
```
- Left 패널에 컬러 스와치 5개 버튼
- Root div에 `style={bgColor ? { background: bgColor } : undefined}`
- 기본값(Dark)은 CSS 변수 활용, 나머지는 inline style 오버라이드
