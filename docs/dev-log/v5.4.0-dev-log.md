## 세부 변경 사항

### [1] Research Bot — 터미널 패널 제거

- `UnifiedBotPage.tsx`: `noTerminal` 조건에 `role === 'research'` 추가
- Research 봇은 하단 XTerminal 패널 없이 순수 패널 UI만 표시
- 이유: Research 봇은 코드 실행이 없으므로 터미널이 불필요하고 공간 낭비

### [2] 사이드바 정리 — 구버전 봇 필터링

- `AppLayout.tsx`: `agents.filter(a => !['ceo', 'design', 'build'].includes(a.role))`
- 사이드바 아이콘 바, BotSubPanel 양쪽 모두 적용
- CEO 봇 완전 제거, 구버전 Design/Build 봇은 Studio Bot으로 통합

### [3] 명칭 변경 — "Design Studio" → "Studio Bot"

- `AppLayout.tsx` NAV_ITEMS label 변경
- 툴팁, 사이드바 네비게이션 전체 반영

### [4] 구버전 봇 라우팅 처리

- `router.tsx` `BotPageRouter` 수정
- `design` / `build` → `/dashboard/design-studio` 리다이렉트
- `ops` → `/dashboard/ops` 리다이렉트
- `ceo` → `/dashboard` 리다이렉트

### [5][6] StudioBotPage — 플로팅 챗 개선

- 위치: `bottom-4 left-1/2` → `top-1/2 left-1/2 -translate-y-1/2` (작업영역 중앙)
- 높이: `h-[280px]` → `h-[200px]`, 확장 시 `h-[380px]`
- "무엇을 만들고 싶으신가요?" 빈 상태 플레이스홀더 제거

### [7] StudioBotPage — 그래픽 디자인 → Canva 통합

- 기존: Ideogram AI 이미지 생성이 주 기능
- 변경: Canva가 주 기능, 카테고리별 템플릿 직접 링크 제공 (소셜미디어/프레젠테이션/마케팅/영상 등)
- Ideogram은 보조 기능으로 전환

### [8] OpsCenter — AX Clinic 스타일 전면 재설계

- 3패널 레이아웃: 좌=도메인 카드, 중=단계별 액션 카드, 우=AI 채팅+n8n JSON
- 도메인: 재무/세무/인사/IT/운영/법률
- 각 프로세스 T1~T7 태그로 분류 (T1=수동브릿지, T2=사일로, T3=지연, T4=포맷, T5=비정형, T6=승인, T7=그림자데이터)
- 빠른 시작 프롬프트 상단 배치
